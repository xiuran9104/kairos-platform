# 漫剧工作流实施任务书（P0 闭环 + P1 工作流打磨）

## 1. 用途与目标

本文是后续 AI 编码代理的实施合同。目标：把 toon 模块打磨成**横屏 16:9 漫剧工作流闭环**，
用一个测试项目从导入小说到导出成片全链路无人工干预断点走通，并在此过程中完成一致性
工程（全局种子 + 风格强制继承 + 全局资产库）、分镜双状态机和统一任务系统。

开始任务前必须阅读根目录 `AGENTS.md`。数据库变化必须走快照工作流：临时编号 SQL → 应用
到参考库 → `bash script/export-database-bootstrap.sh` 重建 `sql/postgresql/0001_initial.sql`
→ 删除编号文件 → `bash script/test-database-migrations.sh` → 更新
`crates/framework/database/tests/migrations.rs` 断言。

上游文档：[漫剧工作流需求](./漫剧工作流需求.md)、[storyboard-sync-plan](./storyboard-sync-plan.md)、
[parity-roadmap](./parity-roadmap.md)。

```text
小说导入 -> 事件图谱 -> Script Agent(骨架/改编/剧本) -> 资产/造型提取
  -> 资产库(项目/全局双层) -> 资产图生成(风格 prefix 继承 + 全局种子)
  -> 分镜表/分镜面板 -> 分镜确认(pending -> ready)
  -> 分镜图生成 -> 图生视频(按模型模式: 单图首帧/首尾帧/多参考)
  -> 配音/音轨绑定 -> 轨道合成 -> FFmpeg 导出成片
        \________ toonflow.tasks 统一任务系统(状态/取消/重试/失败原因) ________/
```

已确认的五项决策（2026-07-28）：

1. 横屏 16:9 为主，`video_ratio` 默认 `16:9`，工作台 UI 横屏优先。
2. P1 纳入分镜双状态机、全局种子、风格强制继承；时间线剪辑、Lip Sync、ControlNet 留 P2。
3. 删除旧 `/toon/*` 脚手架、`toon` schema 与 `toon-api` DTO。
4. 供应商维持 ai-server 统一模型接入，不做 Toonflow 式可编程供应商沙箱。
5. 保持单页工作台，分镜"准备/生成"双状态在页内分区呈现，不拆路由。

## 2. 已建立的框架边界

### 后端（`crates/modules/toon-server/src/`）

- `toonflow.rs`：项目/小说/剧本/资产 CRUD、工作区 flowData、分镜增删改排序、设置与 Agent 部署。
- `toonflow_novel_events.rs`、`toonflow_script_ai.rs`：事件提取、资产/造型提取。
- `toonflow_asset_ai.rs`、`toonflow_image_workflow.rs`、`toonflow_video.rs`、`toonflow_audio.rs`、`toonflow_video_export.rs`：生图、图片编辑流、视频、配音、导出。
- `toonflow_prompt_store.rs` + `toonflow_asset_prompt.rs` + `toonflow_image_edit_prompt.rs`：提示词装配，是风格继承的唯一合法注入点。
- `toonflow_agents.rs` / `toonflow_agent_runtime.rs` / `toonflow_agent_tools.rs` / `toonflow_ws.rs`：Agent 会话、记忆、工具、WS。
- `toonflow_resources.rs`：风格库、任务中心、提示词、Skill。
- `lib.rs`：路由装配，目前同一批 handler 挂在 `/toonflow/**`、`/api/**`、裸路径三套前缀。
- `projects.rs` / `episodes.rs` / `scenes.rs`：旧 `/toon/*` 脚手架，前端零调用，本任务书删除。

### 前端（`apps/web/apps/web-antd/src/`）

- `views/toonflow/projects/detail.vue`：单页工作台（原文/剧本创作/剧本与资产/分镜制作/视频制作）。
- `views/toonflow/projects/StoryboardPanel.vue`、`ProductionFlowCanvas.vue`、`VideoWorkbenchPanel.vue`、`ProductionAssetStrip.vue`、`ImageFlowEditor.vue`。
- `views/toonflow/assets/index.vue` 存在但路由未注册。
- `api/toonflow/index.ts`：约 90 个 API 函数，当前混用 `/api/**` 与裸路径。

### 数据库（`toonflow` schema，28 张表）

`projects`、`storyboards`、`video_tracks`、`videos`、`images`、`assets`、`project_assets`、
`tasks`、`prompts`、`art_styles`、`agent_*` 等。本任务书新增列见第 6 节。

### 模型接入

全部经 `agent_deployments` 绑定 ai-server 统一模型（`AiModelFactory`：chat/image/video/speech）。
这是唯一供应商模式，不引入可编程供应商沙箱。

## 3. 强制架构决策

1. 新建项目 `video_ratio` 默认 `16:9`，存量项目回填；画布与面板按横屏优先布局。
2. 单页工作台不拆路由；分镜双状态机在 `StoryboardPanel` 内分区（准备区/生成区）。
3. 唯一对外前缀 `/toonflow/**`。前端 API 层切换后删除 `/api/**` 与裸路径挂载；WS 收敛到
   `/toonflow/socket/{agent}`；图片代理由公开改为认证或签名 URL。
4. 所有生成类异步操作（事件提取、润色、生图、分镜图、视频、配音、导出）统一落
   `toonflow.tasks`，禁止各域私有状态机散落；任务支持取消与重试，失败原因结构化。
5. 风格强制继承：`art_styles.prefix` 经 `toonflow_prompt_store` 在资产图、分镜图、视频
   提示词三处统一注入，任何生图/视频调用不得绕过。
6. 全局种子：`projects.global_seed` 建项时随机生成；seed 解析顺序为 单点覆盖 > 项目种子 >
   随机；实际使用的 seed 落 `images.seed` / `videos.seed` 保证可复现。
7. 分镜 `confirm_state`（pending/ready）持久化；视频就绪度（有图、有时长、有提示词、关联
   资产齐备）由服务端计算返回，不落库。未 ready 分镜不得进入生图/生视频。
8. 权限码按 `toonflow:资源:动作` 细化，项目与资产按 `user_id` 属主过滤（admin 全量）；
   未实现能力返回明确 404/业务错误，禁止空对象伪成功。
9. 删除旧 `/toon/*` 脚手架与 `toon` schema；`openapi.rs` 以 toonflow 主链路重写。

## 7. Definition of Done

1. 测试项目从导入小说到导出 16:9 成片全链路走通，无人工干预断点。
2. 全部生成任务在任务中心可取消/重试，失败原因结构化可见。
3. 分镜 pending/ready 流转与 readiness 计算正确，未 ready 分镜无法进入生成。
4. 同项目资产图与分镜图均带画风 prefix；生成记录的 seed 可追溯复现。
5. 全局资产可跨项目引用，`/toonflow/assets` 路由可访问。
6. 前端只调用 `/toonflow/**`，旧 `/api/**`、裸路径与 `/toon/*` 一律 404；`toon` schema 不存在。
7. `openapi.json` 覆盖 toonflow 主链路。
8. 无权限请求返回 403 而非穿透；WS 与图片代理不再裸奔。
9. `cargo test --workspace`、`script/test-database-migrations.sh`、前端 typecheck 与 build 全绿。
